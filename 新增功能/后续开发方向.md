# 后续开发方向

## 概述

基于 [tailwind-nextjs-starter-blog](https://github.com/timlrx/tailwind-nextjs-starter-blog) 开源项目，本文档列出 6 个可新增的功能方向，供后续开发者参考。

每个功能都是原项目不具备的独立新功能，开发后可作为项目亮点展示。

---

## 功能一：文章目录（TOC）侧边栏

### 背景

当前项目的 `contentlayer.config.ts` 已经通过 `remark-toc` 插件自动从文章的 Markdown 标题中提取了 `toc` 字段，但 `PostLayout.tsx` 并没有渲染这个数据。长文章阅读时，读者无法快速跳转到感兴趣的章节。

### 功能描述

- 在文章详情页右侧（大屏）显示一个**粘性定位的目录导航栏**
- 自动提取文章中的 H2、H3 标题，生成可点击的锚点链接
- 当前阅读章节高亮显示（滚动监听，自动高亮当前所在章节）
- 小屏设备（移动端）折叠为顶部下拉菜单或侧滑抽屉

### 技术要点

- `contentlayer.config.ts` 中 `Blog` 文档已有 `toc` computedField，包含 `{ depth, value, url }` 数组
- 需要新建 `components/TOC.tsx` 组件，实现滚动监听 + IntersectionObserver 高亮逻辑
- `layouts/PostLayout.tsx` 右侧栏区域已有 `xl:grid-cols-4` 布局，可直接放入 TOC
- 移动端需要额外处理折叠/展开交互

### 难度

🟡 中（核心逻辑简单，滚动监听 + 高亮需要调试）

### 涉及文件

| 文件 | 操作 |
|------|------|
| `components/TOC.tsx` | 新建（目录组件，含滚动监听和高亮逻辑） |
| `layouts/PostLayout.tsx` | 修改（在右侧栏引入 TOC 组件） |
| `data/i18n/zh.ts`、`en.ts` | 修改（添加 `toc.title` 翻译键） |

## 功能二：文章阅读进度条

### 背景

技术博客文章通常较长（2000-5000 字），读者打开文章后无法直观感知文章还有多长、自己读到了什么位置。添加一个顶部进度条可以显著提升长文阅读体验。

### 功能描述

- 在文章详情页顶部显示一个**细长的进度指示条**（高度 3-4px）
- 随页面滚动实时填充，颜色使用 `primary-500` 主题色
- 读完全文时进度条充满，宽度 100%
- 仅在文章详情页显示，首页、列表页等不显示
- 支持亮色/暗色模式

### 技术要点

- 新建 `components/ReadingProgress.tsx`，使用 `useEffect` 监听 `scroll` 事件
- 计算进度：`(scrollTop) / (scrollHeight - clientHeight) * 100`
- 使用 CSS `width` 百分比或 `transform: scaleX()` 实现进度动画
- 在 `PostLayout.tsx` 或 `PostSimple.tsx` 中引入该组件
- 可使用 `requestAnimationFrame` 优化滚动性能

### 难度

🟢 低（逻辑简单，主要是滚动计算 + CSS 动画）

### 涉及文件

| 文件 | 操作 |
|------|------|
| `components/ReadingProgress.tsx` | 新建（进度条组件） |
| `layouts/PostLayout.tsx` | 修改（引入进度条组件） |
| `layouts/PostSimple.tsx` | 修改（引入进度条组件） |

## 功能三：博客归档时间线页面

### 背景

当前项目有首页（最新文章）、博客列表页、标签页，但缺少一个**按时间线展示所有文章**的归档页面。对于技术博客，归档页是读者快速浏览全部内容、按年份查找文章的常见需求。

### 功能描述

- 新增 `/archive` 路由页面，按**年份分组**展示所有已发布文章
- 每组显示年份标题（如 "2025"），下方列出该年的所有文章（日期 + 标题 + 标签）
- 标题可点击跳转到文章详情
- 整体呈时间线视觉效果（竖线 + 圆点标记）
- 支持 i18n：年份标签、页面标题中英文切换
- 支持亮色/暗色模式

### 技术要点

- 新建 `app/archive/page.tsx`，作为 Server Component 获取 `allBlogs` 数据
- 按 `date` 字段降序排列，再用 `reduce` 按年份分组
- 新建 `layouts/ArchiveLayout.tsx` 或在页面内直接渲染时间线 UI
- 时间线样式用 Tailwind 的 `border-l`（竖线）+ `before:` 伪元素（圆点）实现
- 导航栏 `headerNavLinks.ts` 中可添加"归档"入口
- 需要添加 i18n 翻译键：`archive.title`（归档 / Archive）

### 难度

🟡 中（需要新页面 + 新布局 + 时间线 UI 设计）

### 涉及文件

| 文件 | 操作 |
|------|------|
| `app/archive/page.tsx` | 新建（归档页面） |
| `layouts/ArchiveLayout.tsx` | 新建（时间线布局组件） |
| `data/headerNavLinks.ts` | 修改（添加"归档"导航项） |
| `data/i18n/zh.ts`、`en.ts` | 修改（添加归档页翻译键） |
| `app/sitemap.ts` | 修改（Sitemap 中加入 `/archive` 路由） |


## 功能四：相关文章推荐

### 背景

Medium、Hashnode、掘金等平台在文章底部都会展示"相关文章"推荐，帮助读者发现感兴趣的内容，提升页面浏览量和用户停留时间。当前项目文章底部只有"上一篇/下一篇"导航，缺少基于内容相关性的推荐。

### 功能描述

- 在文章评论区上方显示**"相关推荐"区域**，展示 2-3 篇相关文章
- 推荐算法：基于**标签重叠度**排序，取重合最多的文章
- 每篇推荐显示：标题 + 摘要 + 发布日期
- 卡片式布局，支持亮色/暗色模式
- 支持 i18n：区域标题中英文切换（"相关推荐" / "Related Posts"）

### 技术要点

- 新建 `components/RelatedPosts.tsx` 组件
- 接收当前文章的 `tags` 和 `slug`，从 `allBlogs` 中筛选标签重叠最多的文章
- 计算相关性：遍历所有文章，统计与当前文章共享标签的数量，降序取前 3 篇
- 排除当前文章本身
- 在 `PostLayout.tsx` 评论区上方引入该组件

### 难度

🟢 低（标签匹配算法简单，主要是 UI 展示）

### 涉及文件

| 文件 | 操作 |
|------|------|
| `components/RelatedPosts.tsx` | 新建（相关推荐组件） |
| `layouts/PostLayout.tsx` | 修改（在评论区上方引入推荐组件） |
| `data/i18n/zh.ts`、`en.ts` | 修改（添加 `post.relatedPosts` 翻译键） |

## 功能五：文章分享与复制链接

### 背景

几乎所有主流博客平台（Medium、Dev.to、掘金）都在文章顶部或底部提供分享按钮。当前项目已移除 Twitter 链接，但没有提供其他分享方式。添加分享功能可以方便读者将好文章分享给他人。

### 功能描述

- 在文章正文下方（"在 GitHub 上查看"旁）显示分享按钮组：
  - **复制链接**：点击复制文章 URL 到剪贴板，显示"已复制"提示
  - **分享到微博**：打开微博分享窗口，预填文章标题和链接
- 按钮使用小图标 + 文字的组合样式
- 支持 i18n：按钮文字中英文切换

### 技术要点

- 新建 `components/ShareButtons.tsx` 组件
- 复制链接使用 `navigator.clipboard.writeText(window.location.href)`
- 微博分享 URL：`https://service.weibo.com/share/share.php?url=xxx&title=xxx`
- 文章 URL 通过 `siteMetadata.siteUrl + '/' + path` 拼接
- 在三个布局文件中引入（PostLayout、PostSimple、PostBanner）

### 难度

🟢 低（API 简单，主要是多平台分享 URL 拼接）

### 涉及文件

| 文件 | 操作 |
|------|------|
| `components/ShareButtons.tsx` | 新建（分享按钮组组件） |
| `layouts/PostLayout.tsx` | 修改（引入分享组件） |
| `layouts/PostSimple.tsx` | 修改（引入分享组件） |
| `layouts/PostBanner.tsx` | 修改（引入分享组件） |
| `data/i18n/zh.ts`、`en.ts` | 修改（添加分享相关翻译键） |
