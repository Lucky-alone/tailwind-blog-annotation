# 后续开发方向

## 概述

本文档列出项目当前可改进和新增的功能方向，供后续开发者参考。按优先级和难度分类，方便选择适合的任务。

**难度说明**：🟢 低 | 🟡 中 | 🔴 高

---

## 一、高优先级（影响功能/SEO）

### ~~1.1 siteUrl 更新~~ ✅ 已完成
- **说明**：~~`siteMetadata.js` 中 `siteUrl` 仍为模板默认值~~ 已更新为 `https://lucky-alone.github.io/tailwind-blog-annotation`
- **涉及文件**：`data/siteMetadata.js`

### 1.2 OG locale 硬编码修复
- **说明**：`layout.tsx`、`seo.tsx`、博客详情页中 OpenGraph locale 硬编码为 `en_US`，中文博客应设为 `zh_CN`
- **难度**：🟢 低
- **涉及文件**：`app/layout.tsx`、`app/seo.tsx`、`app/blog/[...slug]/page.tsx`

### 1.3 Sitemap 补全
- **说明**：`sitemap.ts` 静态路由缺少 `/about` 页面
- **难度**：🟢 低
- **涉及文件**：`app/sitemap.ts`

### 1.4 Footer 社交链接清理
- **说明**：`siteMetadata.js` 中 github/twitter/facebook 等全部是占位 URL，Footer 显示了无效的社交图标，应清理或填入真实地址
- **难度**：🟢 低
- **涉及文件**：`data/siteMetadata.js`、`components/Footer.tsx`

---

## 二、中优先级（提升用户体验）

### 2.1 文章目录（TOC）侧边栏
- **说明**：`contentlayer.config.ts` 已生成 `toc` 字段，但 `PostLayout` 没有在文章右侧渲染 TOC 侧边栏，长文阅读时无法快速定位章节
- **难度**：🟡 中
- **涉及文件**：`layouts/PostLayout.tsx`，新建 `components/TOC.tsx`

### 2.2 阅读时间显示
- **说明**：`readingTime` 已在 computedFields 中计算，但文章页和列表页都没有展示 "X 分钟阅读"
- **难度**：🟢 低
- **涉及文件**：`layouts/PostLayout.tsx`、`app/Main.tsx`、`layouts/ListLayoutWithTags.tsx`

### 2.3 文章阅读进度条
- **说明**：长文章顶部缺少阅读进度指示器
- **难度**：🟢 低
- **涉及文件**：新建 `components/ReadingProgress.tsx`，在 `PostLayout.tsx` 中引入

### 2.4 项目数据 i18n 支持
- **说明**：`projectsData.ts` 只有中文标题和描述，切换英文后项目页仍显示中文
- **难度**：🟢 低
- **涉及文件**：`data/projectsData.ts`、`app/projects/page.tsx`

### 2.5 搜索快捷键提示
- **说明**：KBar 支持 `Ctrl+K` / `Cmd+K` 触发，但搜索按钮未显示快捷键 badge（如 `⌘K`）
- **难度**：🟢 低
- **涉及文件**：`components/SearchButton.tsx`

### 2.6 启用 Sticky 导航
- **说明**：`siteMetadata.stickyNav` 设为 `false`，用户向下滚动后导航栏消失，建议启用
- **难度**：🟢 低
- **涉及文件**：`data/siteMetadata.js`

### 2.7 404 页面增强
- **说明**：当前只有"返回首页"按钮，缺少搜索框和推荐文章链接
- **难度**：🟢 低
- **涉及文件**：`app/not-found.tsx`

### 2.8 回到顶部平滑滚动
- **说明**：`ScrollTopAndComment.tsx` 使用 `window.scrollTo({ top: 0 })` 缺少 `behavior: 'smooth'`，滚动生硬
- **难度**：🟢 低
- **涉及文件**：`components/ScrollTopAndComment.tsx`

### 2.9 博客列表页搜索
- **说明**：`ListLayoutWithTags` 没有搜索过滤功能，而 `ListLayout` 有但未被使用
- **难度**：🟡 中
- **涉及文件**：`layouts/ListLayoutWithTags.tsx`

## 三、低优先级（锦上添花）

### 3.1 文章分享按钮
- **说明**：文章详情页没有"复制链接"、社交分享等按钮
- **难度**：🟢 低
- **涉及文件**：`layouts/PostLayout.tsx`，新建 `components/ShareButtons.tsx`

### 3.2 动态 OG Image 生成
- **说明**：目前使用静态 `twitter-card.png` 作为社交分享图，可用 `next/og` (ImageResponse) 动态生成带标题的 OG 图片
- **难度**：🟡 中
- **涉及文件**：新建 `app/api/og/route.tsx`

### 3.3 博客归档页
- **说明**：缺少时间线归档页，对于技术博客是常见需求
- **难度**：🟡 中
- **涉及文件**：新建 `app/archive/page.tsx`，新建归档布局组件

### 3.4 Loading 骨架屏
- **说明**：页面切换时无加载指示，可添加 `app/loading.tsx` 显示骨架屏
- **难度**：🟡 中
- **涉及文件**：新建 `app/loading.tsx`

### 3.5 Newsletter 邮件订阅接入
- **说明**：`siteMetadata.js` 配置了 `buttondown`，但 `.env` 中未配置 API Key，组件只是空壳
- **难度**：🟢 低
- **涉及文件**：`data/siteMetadata.js`、`.env`

### 3.6 移动端标签侧边栏
- **说明**：`ListLayoutWithTags.tsx` 标签侧边栏使用 `hidden sm:flex`，移动端完全隐藏，可改为可折叠的手风琴组件
- **难度**：🟡 中
- **涉及文件**：`layouts/ListLayoutWithTags.tsx`

## 四、代码质量改进

### 4.1 NAV_TRANSLATION 重复定义
- **说明**：`Header.tsx` 和 `MobileNav.tsx` 中相同的 `NAV_TRANSLATION` 映射被定义了两次，违反 DRY 原则
- **难度**：🟢 低
- **涉及文件**：`components/Header.tsx`、`components/MobileNav.tsx`

### 4.2 Pagination 组件抽取
- **说明**：`ListLayout` 和 `ListLayoutWithTags` 各自定义了几乎相同的分页组件，应抽取为公共组件
- **难度**：🟢 低
- **涉及文件**：`layouts/ListLayout.tsx`、`layouts/ListLayoutWithTags.tsx`

### 4.3 清理死代码
- **说明**：`layouts/ListLayout.tsx` 存在但没有任何页面引用，是死代码
- **难度**：🟢 低
- **涉及文件**：`layouts/ListLayout.tsx`

### 4.4 TypeScript 类型完善
- **说明**：`Main.tsx`、`BlogPageClient.tsx` 等文件存在大量 `any` 类型，缺少类型标注
- **难度**：🟡 中
- **涉及文件**：`app/Main.tsx`、`app/blog/BlogPageClient.tsx`、`app/seo.tsx`

### 4.5 siteMetadata 迁移为 TypeScript
- **说明**：`siteMetadata.js` 没有类型检查，建议迁移为 `.ts` 并定义完整接口
- **难度**：🟡 中
- **涉及文件**：`data/siteMetadata.js` → `data/siteMetadata.ts`

### 4.6 替换 body-scroll-lock
- **说明**：`MobileNav.tsx` 使用的 `body-scroll-lock` 库在 React 18/19 中有兼容性问题，建议替换为 CSS `overflow: hidden`
- **难度**：🟡 中
- **涉及文件**：`components/MobileNav.tsx`、`package.json`

### 4.7 清理未使用的 import
- **说明**：`BlogPageClient.tsx` 导入了 `allCoreContent`、`sortPosts`、`allBlogs` 但完全未使用
- **难度**：🟢 低
- **涉及文件**：`app/blog/BlogPageClient.tsx`

## 五、部署与运维

### 5.1 CI Workflow
- **说明**：GitHub Actions 仅支持 GitHub Pages，缺少 PR 检查（lint + build 验证）的 CI workflow
- **难度**：🟢 低
- **涉及文件**：新建 `.github/workflows/ci.yml`

### 5.2 依赖自动更新
- **说明**：没有 `dependabot.yml` 或 `renovate.json`，依赖安全漏洞可能无法及时发现
- **难度**：🟢 低
- **涉及文件**：新建 `.github/dependabot.yml`

### 5.3 CSP 配置收紧
- **说明**：`next.config.js` 中 `connect-src *` 和 `img-src *` 过于宽松，应限制为具体域名
- **难度**：🟢 低
- **涉及文件**：`next.config.js`

### 5.4 中文字体优化
- **说明**：Google Font 只加载拉丁子集 `subsets: ['latin']`，缺少中文字体子集支持
- **难度**：🟢 低
- **涉及文件**：`app/layout.tsx`
