# 文章页面完善改动说明

## 概述

对博客文章详情页进行了多项功能完善和体验优化，涵盖评论区交互、外部链接、按钮样式等方面。

---

## 改动清单

### 1. 评论区展开/折叠功能

**文件**: `components/Comments.tsx`

**改动内容**:
- 将原来的一次性"加载评论"按钮改为可重复操作的**展开/折叠切换按钮**
- 首次点击：加载并展开评论区（懒加载，优化首屏性能）
- 再次点击：折叠评论区（隐藏但不卸载，避免重复加载）
- 按钮带有旋转箭头图标，展开时箭头朝上，折叠时箭头朝下，带 300ms 过渡动画
- 评论区使用 `max-height` + `opacity` 过渡动画，展开/折叠过程平滑自然

**i18n 支持**:
- 按钮文字支持中英文切换：加载评论 / 展开评论 / 收起评论
- 对应翻译键：`comments.loadComments`、`comments.expandComments`、`comments.collapseComments`

**技术要点**:
- 使用 `loaded` 状态控制是否已加载（首次加载后不再卸载组件）
- 使用 `expanded` 状态控制显示/隐藏（CSS transition 实现平滑动画）
- Giscus 的 `lang` 字段动态跟随 i18n 语言设置（中文 → `zh-CN`，英文 → `en`）

---

### 2. 评论按钮样式统一

**文件**: `components/Comments.tsx`

**改动内容**:
- 将原来白底灰边的实心按钮改为轻盈的**文字链接风格**
- 使用 `text-primary-500` 主题色文字，无背景无边框
- 悬停时颜色加深（`hover:text-primary-700`），暗色模式适配（`dark:text-primary-400`）
- 带旋转箭头图标（▼ / ▲）指示当前展开/折叠状态，300ms 过渡动画
- 图标与文字间距紧凑（`gap-1.5`）

**效果**: 按钮风格与页面中的标签链接、"在 GitHub 上查看"链接等 UI 元素保持一致，视觉上不会抢夺文章主体内容的注意力

---

### 3. "在 GitHub 上查看"链接

**文件**: `layouts/PostLayout.tsx`、`layouts/PostSimple.tsx`、`layouts/PostBanner.tsx`

**改动内容**:
- 在文章正文下方添加"在 GitHub 上查看"链接
- 点击后跳转到对应文章的 `.mdx` 源文件（GitHub 仓库中）
- URL 拼接规则：`${siteRepo}/blob/main/data/${filePath}`
- 三种文章布局（PostLayout、PostSimple、PostBanner）均已支持
- 采用经典蓝色超链接样式：`text-blue-600`，悬停加深并显示下划线
- 暗色模式适配：`dark:text-blue-400 dark:hover:text-blue-300`

**配置依赖**:
- `siteMetadata.siteRepo` 需设置为正确的 GitHub 仓库地址
- 当前值：`https://github.com/Lucky-alone/tailwind-blog-annotation`


### 4. Giscus 评论配置完善

**文件**: `data/siteMetadata.js`、`.env`

**改动内容**:
- 将 Giscus 所有 11 个配置项全部通过环境变量管理
- `.env` 文件中每个配置项都附带详细的中文注释说明
- `siteMetadata.js` 中所有字段从 `process.env` 读取，并提供默认值兜底
- 新增 `strict`、`inputPosition`、`theme` 等之前缺失的配置字段

**完整配置项清单**:

| 环境变量 | 功能 |
|---|---|
| `NEXT_PUBLIC_GISCUS_REPO` | 评论存储的 GitHub 仓库 |
| `NEXT_PUBLIC_GISCUS_REPOSITORY_ID` | 仓库唯一 ID |
| `NEXT_PUBLIC_GISCUS_CATEGORY` | Discussion 分类 |
| `NEXT_PUBLIC_GISCUS_CATEGORY_ID` | 分类唯一 ID |
| `NEXT_PUBLIC_GISCUS_MAPPING` | 页面与 Discussion 映射方式 |
| `NEXT_PUBLIC_GISCUS_STRICT` | 严格标题匹配 |
| `NEXT_PUBLIC_GISCUS_REACTIONS` | Emoji 表情反应 |
| `NEXT_PUBLIC_GISCUS_METADATA` | 元数据发送 |
| `NEXT_PUBLIC_GISCUS_INPUT_POSITION` | 评论输入框位置 |
| `NEXT_PUBLIC_GISCUS_THEME` | 评论区主题 |
| `NEXT_PUBLIC_GISCUS_LANG` | 界面语言（动态覆盖） |
