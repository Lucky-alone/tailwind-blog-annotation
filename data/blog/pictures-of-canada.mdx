# CSS Grid与Flexbox布局实战

现代Web开发中，CSS Grid和Flexbox是两大核心布局方案。本文将通过实际案例，帮助你掌握这两种布局方式的精髓。

## Flexbox：一维布局利器

Flexbox适合处理一维布局（一行或一列），是最常用的布局方式。

### 基础示例

```css
.flex-container {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 1rem;
}

.flex-item {
  flex: 1;
  padding: 1rem;
}
```

## CSS Grid：二维布局神器

CSS Grid适合处理二维布局（同时控制行和列），是构建复杂页面布局的最佳选择。

### 基础网格

```css
.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: auto;
  gap: 20px;
}
```

### 响应式网格

使用`auto-fill`和`minmax`实现自适应网格：

```css
.auto-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
  gap: 1.5rem;
}
```

### 实战：仪表盘布局

```css
.dashboard {
  display: grid;
  grid-template-areas:
    "header header header"
    "sidebar main main"
    "sidebar footer footer";
  grid-template-columns: 250px 1fr 1fr;
  grid-template-rows: 60px 1fr 40px;
  height: 100vh;
}

.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }
```

## Flexbox vs Grid：如何选择

| 场景 | 推荐方案 | 理由 |
|------|---------|------|
| 导航栏 | Flexbox | 一维水平排列 |
| 卡片列表 | Grid | 二维网格布局更直观 |
| 居中对齐 | Flexbox | 语法简单 |
| 复杂页面布局 | Grid | 精确控制行列 |
| 不等宽列 | Grid | grid-template更灵活 |
| 工具栏 | Flexbox | 项目自动排列 |

## 总结

Flexbox和CSS Grid各有优势，在实际开发中经常配合使用：

- **Flexbox** 处理组件内部的元素排列（导航栏、按钮组、表单）
- **Grid** 处理页面级的整体布局（仪表盘、画廊、文章排版）

掌握这两种布局方式，你就能应对几乎所有的Web布局需求！
